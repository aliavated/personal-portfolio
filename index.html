02 / INTERACTIVE EXPERIMENT

A small problem, made visible.

A simplified pathfinding demonstration. It uses breadth-first search to explore a grid and find a shortest route when one exists. Try it, change the obstacles, and see what happens.

EXPERIMENT 001

Finding a way through.

A pathfinding algorithm searches a space of possible positions. In this example, each cell is a position and blocked cells represent obstacles. The search checks neighbouring cells until it reaches the destination or runs out of options.

Breadth-first search is useful here because every move has the same cost. It finds a route with the fewest steps, though it does not account for different terrain costs.

METHOD: BREADTH-FIRST SEARCH
MOVEMENT: FOUR DIRECTIONS
COST PER MOVE: 1
